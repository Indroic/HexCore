## Why this documentation is split in two

The package README is what npm renders, so it has to stand on its own for somebody who arrived
from a search result and has not cloned anything. These guides are for somebody who is already
building: they go deeper, they cross-reference the server side, and they say what goes wrong
when you get a choice backwards.

Both are maintained. When they disagree, the guides are the more specific of the two — and
[English](./en/) is the reference version of the guides.
